## Phase 3 — Materialize

### 3A — Direction proof

- [ ] **3A.1** Tool path chosen (hand / AI / contractor / hybrid)
- [ ] **3A.2** Standalone consumable spec written (paste blocks)
- [ ] **3A.3** Cheap proof generated (grayscale / stub / wireframe)
- [ ] **3A.4** Critique @ agreed scale — pass / conditional / fail per item
- [ ] **3A.5** Discuss & resolve (if needed) — observe → decide → **write**
- [ ] **3A.6** Identity lock note (if plan was thin)
- [ ] **3A.7** Retry (solo / hybrid / targeted fix)
- [ ] **3A.8** Composite set review (if applicable)
- [ ] **3A.9** Owner approve 3A before polish / 3B
- [ ] **Exit:** sort test passes without labels

### 3B — Production-ready (after 3A)

- [ ] **3B.1** Polish pass (color / fidelity — accent threads only if art)
- [ ] **3B.2** Scale cleanup (import-ready format)
- [ ] **3B.3** Context test (board / UI / background)
- [ ] **3B.4** Composition still (if in scope)
- [ ] **3B.5** Approve 3B — ready for build
- [ ] **Exit:** import-ready artifacts

## Materialize — discuss & resolve (when output exposes gaps)

Use when: sort fail · identity fork · collision · prop ambiguity · tool artifact

- [ ] **Observe** — what did output actually do?
- [ ] **Diagnose** — plan gap / tool failure / fixable drift?
- [ ] **Decide** — one lane; park alternatives
- [ ] **Write** — brief amend · identity note · prompt delta
- [ ] **Retry** — regen or manual fix
- [ ] **Re-test** @ agreed scale

---

## Phase 4 — Code (MVP)

- [ ] Approved assets / stubs imported
- [ ] Thin playable/runnable slice (scoped DoD)
- [ ] Readability stack in frame
- [ ] MVP metrics checklist pass
- [ ] Docs ↔ build aligned
- [ ] **Exit:** MVP DoD met

---

## Phase 5 — Refine

- [ ] Entered only after MVP DoD
- [ ] Polish / breadth / doc sync
- [ ] Debt logged
- [ ] **Exit:** diminishing returns

---

## Phase 6 — Publish

- [ ] Ship target defined
- [ ] Artifact released
- [ ] Retrospective (optional)

---

## Allowed loops (conscious, not drift)

- [ ] Materialize → plan-light (identity note) — written
- [ ] Materialize → Materialize (retry) — logged
- [ ] Code → Materialize (proof wrong) — scoped

**Not allowed:** polish before 3A.9 · MVP before Materialize approve · Refine before MVP

---

## Anti-patterns quick scan

- [ ] Reference is not the spec
- [ ] No batch AI when singles needed
- [ ] Collisions differentiated where required
- [ ] Discussion written, not chat-only
- [ ] Phase pin matches actual work
