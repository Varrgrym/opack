## Interview A→F

Run in order. Stop when the slot is obvious. Label answers: fact · observation · conclusion · assumption · open Q · recommendation · **decided** · **NOT** · parked.

### A — Identity
1. Is this a **craft/job**, a **brand/face**, a **method**, a **product**, a **channel/content**, a **runtime**, or only a **loop arrow**?
2. If we deleted the name, what physical or computational **job** remains?
3. Ownership: yours / Active Keep · parked · **NOT**?

### B — Parent test
4. What is the **parent organism** (company, hub, life’s-work frame)? One sentence.
5. Which of the **≤4 cores** would still make sense if this were the only thing that parent did in that lane?
6. If it seems to need a **5th peer parent**: what job is *not* already covered? (Force one sentence — or nest it.)
7. Are we confusing **origin brand / satellite** with **core craft**?

### C — Nest vs peer (domain-shaped)
8. Is the primary output a **shared endpoint** of another core (e.g. compost/frass→soil; logs→Memory), or a **distinct product/job**?
9. Is this a **prestage**, a **pathway**, or an **endpoint**?
10. If it “feeds” another core, is that **craft home** or only **downstream use**?
11. Safety / refuse: what must **never** connect (e.g. pathogen streams → juice prestage)?

### D — Connections (coupling discipline)
12. Inputs? Outputs? Name them as matter, runtime signals, or artifacts — not slogans.
13. Which coupling diagram stage does this sit on — or why claim it if it doesn’t appear?
14. Which other cores does it **feed**, **draw from**, or **bridge** — load-bearing vs optional?

### E — Evidence & home
15. Durable write-up where? (organism spine · specialist beat card · thematic notebook · Excel/raw SoT · only chat)
16. Thin fragment → park bucket; don’t promote noise into the tree.
17. What would **falsify** this placement in six months?

### F — Anti-sprawl
18. New top-level from excitement, or because the job is distinct?
19. Can two existing nodes absorb it with a clearer **arrow** instead of a new box?
20. What is explicitly **NOT** under this parent?

## Deliverables (DoD for one organism pass)

When the interview (or a contested-node batch) lands, produce or update:

1. **Parent one-liner** (what the organism *is* — not every value stream).
2. **≤4 core crafts/jobs** with nesting (methods/brands under cores).
3. **Connected map** (mermaid or equivalent) — tree ≠ flows; keep both.
4. **Topic / source router** — where detail lives; flowchart/diagram stages → homes.
5. **Ownership table** + **NOT** list.
6. **Open questions** for operator (park; don’t invent answers).
7. Optional later: **beginner front door** (story → rooms → loop picture) for WP/others — separate from accuracy spine.

**Stop when:** remaining items are thin, already routed, or waiting on operator pins.

## High-leverage rules

- **Method is the tool** — reuse A→F; do not re-derive from vibes each time.
- **Density gate** — full organism campaign only when fragments are thick (many sources, brands, loops). Otherwise extract + park.
- **Steal process, not labels** — Garden/runtime cores ≠ Horticulture/Composting unless the interview proves the same *jobs*.
- **Reliability honesty** — modular intent ≠ proven long-run (call it).
- **Distinct subtypes beat false umbrellas** when profiles differ (e.g. named frass types).
- Pairs with extract: Keep/Park personal; reject only PII/secrets/ops noise.
