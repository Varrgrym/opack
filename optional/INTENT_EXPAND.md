# Intent expand (workflow lab)

**Status:** active consolidated kit · 2026-08-08  
**Archives:** `archive/ADAPTIVE_TASK_EXPANSION.md` · `archive/UNIVERSAL_DEEP_REASONING.md` · `archive/ANALYSIS_PROMPT_PLATFORM.md`  
**Use when:** short human intents need the right rigor — not maximum ceremony  
**NOT:** Layer A by default · inventing scope · trivia theater

---

## Operating principle

The operator provides **intent**.  
Expand to: prompt → context → specification → mode/seat → plan → execution → evaluation → stop.

**My request is the starting intention, not the full specification.**  
Make every task **as rigorous as it needs to be, and no more.**

---

## Automatic 5W1H

Always reason; **show** on substantial work:

| Q | Ask |
|---|-----|
| Who | Affected / owner / consumer |
| What | Systems, files, behaviors involved |
| Why | Real goal / problem |
| When | Lifecycle, sequencing, timing |
| Where | Paths / ownership in the repo |
| How | Current vs desired mechanism |

Certainty labels: **Known → Inferred → Unknown → Recommended**. Do not invent facts.

---

## Depth dial

| Task | Depth |
|------|--------|
| Trivia / lookup | Answer; skip ceremony |
| Local code question | Relevant files + docs; prefer existing impl |
| Errors / architecture / readiness | Broader inventory; second-order causes; contradictions |
| **“Review this project”** / fine-tooth / full review | **Mode D** + coverage bar below — **do not ask which mode** |

---

## Project-review coverage bar (§ phrase lock)

Minimum (all required unless N/A — say why):

1. Purpose / intended behavior  
2. Structure + major entry points  
3. What tests actually prove (run when practical)  
4. Doc ↔ code drift  
5. Gaps / duplication / complexity  
6. Strengths to preserve · what NOT to touch  
7. Prioritized next / do-not · stop evidence  

Too large → semantic chunks → **synthesize before conclusions** (`CHUNKING.md`). Optional Archivist spike with a **named** question → hand off. **No review fleets.**

Open with runtime stanza: `Mode=D · Seat=… · Multitask=off · Plan=?` (`RUNTIME.md`).

Cold-lead posture: `MODE_D.md`.

---

## Decide-next close (substantial work)

End with: **Do now / next / later / do not** · milestone proof · what would change the recommendation. Prefer consolidate/stop over new subsystems.

---

## Extract / organize phrase lock

“Extract what is useful” / “organize the repo” / chat dumps → `EXTRACT_AND_ORGANIZE.md` (filter → map → land **net-new only**). Video / YouTube / “without watching it myself” → `VIDEO_EXTRACT.md`.

---

## Do not overreach

Do not invent requirements, rewrite working systems for taste, treat speculation as evidence, or continue after the objective is met. When correct: **“This is already good enough; stop.”**
